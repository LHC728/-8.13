## 1. 使用与变更规则

1. 检查 ID 永不复用。修改检查含义时提升注册表版本并保留旧版映射；不得在其他文件中重新定义 `C01`–`C25`。
2. 每份验证报告至少记录：`registry_version`、`check_id`、`status`、实际命令、输入/输出版本、失败样本和 `schema/config/code/key/log` 哈希。
3. `硬门`失败时阻断其列明的阶段或产物；`H2门`只阻断 H2，不阻断 H1/R1；`统计诊断`触发调查，但不得因一次普通 95% 区间未覆盖就反复换种子。
4. 主模型与检查器共享同一只读 canonical 参数和 schema；独立的是求根、状态转移、可行性与指标复算代码，不得“独立生成另一套参数”。
5. G2 只实现本表列明的最小范围，不等于运行 100 台正式实验、启用 H2 或冻结论文数字。
