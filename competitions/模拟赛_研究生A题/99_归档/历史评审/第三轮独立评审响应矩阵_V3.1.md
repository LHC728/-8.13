# 第三轮独立评审响应矩阵 V3.1

> **决策证据而非执行规格：当前口径已落入问题契约、`CURRENT_STATE.md` 和 `CR-V3.1`；实现任务无需默认读取本评审过程。**

> 本表记录第三轮 G1 冻结稿评审、再裁决及队伍最终签字。它不包含任何 100 台正式运行数字。当前执行规范以问题契约和 `CR-V3.1` 为准。

| 条目 | 最终裁决 | 落地规则 |
|---|---|---|
| P1 Y3语义排序 | **重新签字采纳** | 单次无条件 `(1-q)alpha=q beta=e/2` 升为题面字面主情景；标准初测—触发重测链降为关键替代情景；两套均从A/B/C到`q_E`、E核、四格、工期和K完整重算 |
| P2 lambda等价性 | **澄清后采纳** | 三种口径的TP计数不同；相同的是归一后的来源比例。禁止把“比例等价”写成“计数相等” |
| P3 E重测对象 | **驳回事实判断，采纳表达加固** | 契约已冻结E异常后完整重做E；论文假设表再明写一次，不返回被指向子系统 |
| P4 H2删除后的创新 | **采纳** | H2删除时只保留两项模型创新；随机带、oracle和重放仅列验证体系 |
| P5预防更换 | **部分采纳** | G3冻结H1触发式与`tau_pm`候选；不以此阻断G2，也不在无日志时拍定最终阈值 |
| P6班末禁启弱支配 | **不采纳定理化** | 设备年龄、故障与更新策略交互下尚未证明弱支配；继续作为队伍操作约束，不再援引方向含混的“暴露故障”理由 |
| P7 YXB分母 | **部分采纳** | 表2保留名义班长主口径；可另报“实际开放班时利用率”，必须改名且不得替代表2 |
| P8 K=12弱支配 | **驳回主情景，评审已撤回** | 主情景班界不同步、可行窗口不嵌套，必须枚举七个K；只有无缝续测且允许主动空闲的退化情景可证K=12弱支配 |
| P9符号冲突 | **采纳** | 到达E概率用`G`，无/有问题到达量用`Z_0/Z_1`，预防阈值用`tau_pm`；状态集合不得复用这些符号 |
| P10首两台到位 | **采纳披露** | 标为队伍初始化闭合，不伪装成题面逐字事实 |
| P11班外全停 | **采纳披露** | 标为队伍班历闭合假设 |
| P12校准/闲置不计龄 | **采纳披露** | 闲置、停工、校准不计设备运行年龄；校准中不故障；必要时另做“校准计龄”低成本情景 |
| P13中断后的观测键 | **解释后采纳** | `U_Y`是有效完成结果的延迟物化随机数；作废物理片段不产生、观察或消费观测U，并非复用一个已发生结果 |
| P14 lambda闭合 | **采纳披露** | 多故障等权、假阳性排除均为必要闭合假设；若统计全部报告方向须另建假阳指向核 |
| P15 A/B/C并行 | **采纳披露** | 标为题面强支持但非唯一的队伍解释；串行情景保留 |
| P16 E单核与指向 | **采纳披露** | 身份对称受题面支持；检出率不随故障数变化、指向不改流程是简约闭合 |
| P17固定FCFS | **采纳披露** | FCFS是可复现策略限制，不是题面硬约束；最优性只限冻结候选集 |
| P18 Q3手算例 | **采纳** | 增加3台、K=9、跨班重测时间线，联合检查C08/C11/C12 |
| P19 lambda区间 | **部分采纳** | Q1解析lambda无MC误差；G3经验lambda以整批为聚类单位报告不确定性 |
| P20确定性参照 | **可选** | 可作容量sanity check；没有严格松弛证明时不得称工期下界 |
