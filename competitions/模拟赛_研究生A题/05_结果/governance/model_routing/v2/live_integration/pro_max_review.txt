VERDICT: BLOCKED

FINDINGS:

**1. What the two choices mean semantically.** For N subjects with mᵢ rows each (M = Σmᵢ rows total) and within-subject correlation ρ (ICC), the resampling unit is a statement about which objects are exchangeable — i.e., a model of the data-generating process (DGP), not an implementation detail. The actual DGP of repeated-measurements data is two-stage: subjects are the primary sampling units; rows are conditionally dependent within subjects.

**2. Row-level (observation-level) resampling — semantics.**
- Mechanism: M rows drawn i.i.d. with replacement from the M observed rows; subject labels kept but not respected as blocks; block sizes in each resample become multinomial noise.
- Dependence structure: the bootstrap world's DGP is "rows are independent draws from a single row superpopulation". Within-subject dependence (exchangeable or serial/AR) is therefore *destroyed at the resampling boundary*: it survives only marginally in the empirical row distribution, not in the induced sampling variability.
- Standard error: for the mean, bootstrap variance targets σ²_row/M (the i.i.d. variance). Under clustering the true variance is σ²_row/M × (1 + (m̄−1)ρ) (design effect DEFF). With ρ > 0 the row bootstrap underestimates the SE by ≈ √DEFF → CIs too narrow, p-values and Type I error anti-conservative, false precision.
- Inference validity: valid only when rows are (essentially) independent, i.e., only when subject identity carries no dependence — which contradicts the repeated-measures design. Even the ρ=0 case is a modeling claim that would itself have to be frozen and defended, not assumed.
- Secondary defect: it silently reweights subjects by their observed row counts, so subject-level statistics (e.g., mean of subject means) are biased toward high-mᵢ subjects.

**3. Subject-level (cluster) resampling — semantics.**
- Mechanism: N subjects drawn with replacement; each drawn subject's full row block kept intact; total rows vary per resample.
- Dependence structure: preserves the actual two-stage DGP by construction — blocks are never split, so any within-subject covariance form (exchangeable, serial, heteroscedastic) is carried into every resample.
- Standard error: reflects between-subject variability; the bootstrap SE of the size-weighted mean approximates the cluster-robust (sandwich) SE as N→∞; effective sample size is N, not M.
- Inference validity: the correct level for inference about a population of subjects; consistent under cluster exchangeability for large N.
- Caveats: (i) small N → coarse resample support (≈2^N distinct draws), percentile CIs unreliable → fallbacks: cluster-robust SE with CR2/CR3 small-sample corrections, wild cluster bootstrap, or cluster-respecting permutation tests; (ii) unbalanced mᵢ and row-level estimands need an explicit weighting rule; (iii) if rows are themselves a within-subject subsample, a two-stage bootstrap (resample subjects, then rows within subject) is the fuller mimicry; (iv) the number of clusters resampled (fixed N, or other) must be frozen.

**4. Trade-off.**

| Dimension | Row resampling | Subject (cluster) resampling |
|---|---|---|
| Exchangeability assumed | rows i.i.d. | subjects i.i.d., rows conditionally dependent |
| Within-subject dependence | broken at resampling boundary | preserved by construction |
| SE when ρ > 0 | underestimated ≈ √(1+(m̄−1)ρ) | consistent with cluster-robust SE |
| Inference validity | invalid under clustering; anti-conservative | valid for large N; small-N corrections needed |
| Effective sample size | M (illusory) | N (correct level) |
| Estimand compatibility | row-level targets only | subject-level and (with weighting rules) row-level |
| Implementation | no cluster IDs needed | needs cluster IDs + block/weight rules |

**5. What must be decided before the analysis can proceed** (decision-layer items, none of which a reviewer or implementer may default):
- **D1 — Estimand:** population of subjects vs population of observations; the corresponding statistic (mean of subject means vs size-weighted overall mean). The unit must follow the estimand, not vice versa.
- **D2 — Resampling unit:** subject (cluster) vs row, formally frozen. Statistically, subject-level is the only choice consistent with the repeated-measures dependence unless D1 explicitly redefines the target as an independent-row superpopulation (an extraordinary ρ=0 claim requiring justification). If treatment varies at row level (e.g., crossover design), the experimental unit must additionally be checked — the generic rule cannot be assumed to transfer.
- **D3 — Bootstrap mechanics:** cluster count per resample, block handling, unbalanced-mᵢ weighting, B, seed/namespace policy, CI type (percentile/BCa/t-based), and whether the bootstrap SE must be cross-checked against a cluster-robust analytic SE.
- **D4 — Model alignment:** the chosen unit must be consistent with the primary model's dependence assumptions (mixed-effects / GEE with cluster-robust SE); no silent mismatch between model SE and bootstrap SE.
- **D5 — Small-N policy:** threshold on N below which plain cluster bootstrap is disallowed (CR2/CR3, wild cluster bootstrap, or permutation instead).
- **D6 — Governance landing:** D1–D5 frozen in the authority files (问题契约 / CURRENT_STATE / CHANGELOG, per the workspace change discipline) with decision-layer + team confirmation, before any implementation or result generation; thereafter bound to run config/manifest.
