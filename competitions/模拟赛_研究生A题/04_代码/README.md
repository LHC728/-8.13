# 代码目录说明

本目录只说明长期职责和隔离边界，不代表代码已经完成。当前 Gate 与实现进度只看 `../CURRENT_STATE.md`。

## 目录职责

- `main_model/`：主模型实现，只依据冻结契约和任务包编码。
- `checker/`：独立检查器，不得导入主模型的求根、状态转移、可行性或指标函数。
- `tests/`：单元测试、性质测试和回归测试；手算输入放在 `tests/fixtures/`。
- `scripts/`：运行编排、验证和产物整理脚本。
- `src/`：仅允许放不含数学判断的公共基础设施，例如只读配置解析和通用序列化；不得借此共享主模型与 checker 的核心逻辑。

## 开工条件

1. 先读取 `../CURRENT_STATE.md`、问题契约、`CR-V3.1` 和冻结任务包。
2. 低级执行模型不得补充默认值；发现未定义行为时立即提交“事实—选项—影响—建议”。
3. 只实现 `CURRENT_STATE.md` 和当前检查注册表授权的范围；不得提前进入后续 Gate。
4. 运行产物只能写入 `../05_结果/run_<id>/`，不得写回源码目录。
