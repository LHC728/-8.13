# 模拟赛：大型装置测试任务规划

本项目以 2025 年湖南省研究生数学建模竞赛 A 题为题源，按全国大学生数学建模竞赛 B 题的评价习惯完成建模、验证和论文。

## 当前状态

Gate、当前权威版本、实现进度、正式数字状态和下一步只以 [CURRENT_STATE](CURRENT_STATE.md) 为准，不从本页、目录是否存在或历史评审推断。

## 新对话默认入口

按顺序读取以下 5 项即可开始当前工作：

1. [CURRENT_STATE](CURRENT_STATE.md)：当前 Gate、权威指针、正在做和禁止事项；
2. [问题契约](01_审计/问题契约.md)：题意、状态、流程和指标；
3. [检查注册表 CR-V3.1](01_审计/检查注册表_V3.1.md)：唯一验收定义；
4. [参数表](02_数据/parameters.csv)：机器可读题面参数；
5. [当前模型总览](03_模型/00_模型总览.md)：数学路线与专项模型导航。

随后仅按任务需要读取 [项目计划](08_项目管理/项目计划.md) 和 [风险清单](08_项目管理/风险清单.md)。历史评审、旧方案和旧注册表不在默认阅读路径。

## 数字纪律

- 所有正式数字必须来自实际运行、通过独立检查并冻结的结果文件。
- 主模型与 checker 分实现，不能相互导入核心求根、状态转移、可行性或指标函数。
- 每次正式运行必须绑定参数、配置、代码、随机键、日志和检查报告。
- 旧版本和聊天记录仅供追溯；发生冲突时按 `CURRENT_STATE.md` 指定的权威链处理。
