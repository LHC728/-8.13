# G2 手算样例：K=9 的三台装置跨班重测

> 用途：`CR-V3.1/C08` 的确定性验收样例，并联合检查 C09、C11、C12。这里的数值是人工构造的测试夹具，不是题目 100 台正式结果。

## 1. 固定输入

- Q3 两班制，`K=9 h`：第一班 `[0,9)`、第二班 `[9,18)`；两班之间无空档，但在途活动不可交接。
- 两个驻留台位；A/B/C/E 时长分别为 2.5/2/2.5/3 h；主周转为 1 h。
- 关闭设备随机故障、预防更换和观测随机抽样，直接指定观测结果。
- 三台装置真实状态全部正常。仅装置 3 的 B 初测指定为异常，B 重测指定为正常；其余有效测试均正常。
- 第一班由 `squad_id=1` 执行，第二班由 `squad_id=2` 执行。

## 2. 人工事件时间线

| 时间区间/时刻 | 资源与事件 | 预期状态更新 |
|---|---|---|
| `[0,2)` | 装置1-B | B 初测通过 |
| `[0,2.5)` | 装置1-A、装置1-C 并行 | A/C 同刻通过，装置1在2.5释放E |
| `[2,4)` | 装置2-B | B 初测通过 |
| `[2.5,5)` | 装置2-A、装置2-C 并行 | A/C 同刻通过 |
| `[2.5,5.5)` | 装置1-E | 装置1在5.5终局通过 |
| `[5.5,6.5)` | 台位1复合周转 | 装置1运出、装置3运入；台位1不可测试 |
| `[5.5,8.5)` | 装置2-E | 装置2在8.5终局通过 |
| `[6.5,8.5)` | 装置3-B 初测 | 8.5报告异常，生成B重测：`release_time=8.5`、`effective_attempt_no=2` |
| `[6.5,9)` | 装置3-A、装置3-C 并行 | 在9.0恰好完成；先结算完成，再换班 |
| `8.5` | B重测派工判断 | 第一班仅余0.5h，小于2h，禁止启动；任务保留原FCFS键且装置继续占台 |
| `[9,11)` | 装置3-B重测 | 由第二班 `squad_id=2` 从头完整执行并通过；不是插队 |
| `[11,14)` | 装置3-E | 14.0终局通过，任务立即停止，不运出末台 |

装置2在8.5终局后，因为已经没有待运入装置，不启动“空运入”的1 h复合周转；其台位可记为 `terminal_occupied_until_stop`。这不得影响装置3或总工期。

## 3. 必须完全匹配的验收量

- `T = 14 h`，共计入两个计划班次，YXB主口径分母为 `2×9=18 h`。
- A测试片段总时长 `7.5 h`，`YXB_A=7.5/18`。
- B测试片段总时长 `8 h`，`YXB_B=8/18`。
- C测试片段总时长 `7.5 h`，`YXB_C=7.5/18`。
- E测试片段总时长 `9 h`，`YXB_E=9/18`。
- `S=3`、`PL=0`、`PW=0`。

## 4. 路径硬断言

1. 装置3的 B 重测逻辑释放时刻始终为8.5，换班时不得改成9.0。
2. B重测的有效尝试号为2；`U_Y` 键不含 `squad_id`、物理重启号或班次。
3. B重测执行片段的 `squad_id=2`，但观测核与第一班相同。
4. 9.0时A/C完成先结算，不能因换班被错误取消。
5. 待重测跨班期间装置3始终占用原台位。
6. 容器遍历次序打乱后，canonical事件集合和上述结果保持一致。
