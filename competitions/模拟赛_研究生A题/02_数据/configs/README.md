# 运行配置目录

这是本项目唯一的正式运行配置目录。当前是否已有可执行配置只看 `../../CURRENT_STATE.md`；不得为填满目录而创建带未决字段的伪配置。

后续每个配置必须：

- 只引用 `parameters.csv` 中的题面参数，不复制出第二套参数事实；
- 明确 `scenario_id`、观测语义、周转情景、班历、策略、K、预防阈值和随机键规范；
- 写入问题契约版本、`CR-V3.1`、参数哈希与配置 schema 版本；
- 未定义项显式失败，禁止依赖代码默认值；
- 主情景、标准链替代、0.5 h 周转等使用不同不可混淆的配置文件和结果目录。

正式配置由 G2 任务包冻结后再创建。测试 fixture 放 `04_代码/tests/fixtures/`，不得伪装成正式运行配置。
